About the Project

The LLM & ML Enhanced Software Testing System connects static code analysis, machine-learning risk prediction, large-language-model test generation, and isolated test evaluation in one automated quality workflow.

How it works

System Architecture

The challenge

The Problem

AI-generated tests can fail for many different reasons: a real defect, an incorrect expectation, invalid generated code, or a problem in the test environment. Without clear evidence, it is difficult to know what to fix or whether the tests are useful.

The approach

Our Solution

The pipeline prioritizes risky code, generates targeted tests, and executes them in an isolated Docker sandbox. It combines test outcomes, coverage, and mutation evidence to classify failures and produce a clear A/B/C/D quality grade.
